# BCC College Department Payroll — sign-in screen

This version is a single responsive sign-in page for the Binangonan Catholic College College Department Payroll office. The page markup is in `public/index.html` and its small interactive behaviors are in `public/app.js`; styling is in `public/assets/styles.css`.

## Run with XAMPP

1. Copy the project into XAMPP's `htdocs` directory.
2. Start Apache in the XAMPP Control Panel.
3. Open `http://localhost/bcc-payroll/public/` (use your folder name if different).

This is a static UI prototype. The form validates required fields and displays a message, but does not authenticate users or send/store credentials. Do not enter real passwords. No database is required for this version.
